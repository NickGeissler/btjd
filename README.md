# Block-Triangular Joint Drifting (BTJD)

Code for [*One-Step Generative Surrogate Models via Block-Triangular Joint
Drifting*](https://arxiv.org/abs/2609.26435) (BTJD).

This repository reproduces the four experiments of the paper. With the released
data and weights, every table and figure is regenerated by

```bash
bash scripts/download_data.sh
bash scripts/evaluate_pretrained.sh
```

Both training and evaluation is reproduced via `bash scripts/run_<domain>.sh`.

## Installation

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Pinned versions in `requirements.txt`. All commands are run from the repository root as modules (`python -m <domain>.<script>`).

## Layout

```
data/        datasets for all four experiments (obtained from data download)
checkpoints/ released weights
common/      Sinkhorn drifting field, plotting code
duffing/     generate_data, model, train, evaluate, plot_snapshots, plot_ensemble
rb/          generate_data, model, train, evaluate, plot_histograms
burgers/     autoencoder, train_autoencoder, model, train, evaluate, plot_snapshots
cfd/         normalize_data, autoencoder, train_autoencoder, encode_to_latent,
             feature_net, pretrain_feature_net, drift_loss, generator, train,
             evaluate, plot_snapshots, plot_ensemble
scripts/     run_<domain>.sh: training and evaluation for each experiment;
             download_data.sh, evaluate_pretrained.sh
```

`scripts/run_<domain>.sh` runs training, evaluation and figures in order.

## Data

The datasets are hosted at
[huggingface.co/datasets/NickGeissler/btjd-data](https://huggingface.co/datasets/NickGeissler/btjd-data).

```bash
bash scripts/download_data.sh
```

```
data/
  duffing/paper/{train,test}.npy        5000 + 5000 trajectories, X(0) ~ N([0,-10], I)
  duffing/fixed_x0/test.npy             5000 trajectories from X(0) = (0, -10)
  duffing/pool_{distIC,x0}/test.npy     200 000-trajectory pools for the QoI
  rb/RB_train_mu{13.50,...,14.20}.npy   20 000 trajectories per training mu
  rb/RB_test_mu13.65.npy                held-out mu
  burgers/StochBurgers{Train,Test}.npy  [4096, 800, 64] each
  cfd/stochasticJCFDTrain.npy           raw vorticity, [2048, 1000, 64, 64, 1]
  cfd/stochasticJCFDTest.npy            [1024, 1000, 64, 64, 1], independent ICs
  cfd/test_{normalized,latent}.npy      test set normalized and encoded with the
                                        released autoencoder (checkpoints/cfd)
  cfd/operator_rollouts_ic0.npz         operator-learning baseline, 3 rollouts from
                                        test IC 0 (turbulence ensemble figure)
```


## Paper results → commands

| Paper item | Produced by | Output |
|---|---|---|
| Table 1 (Duffing) | `duffing.evaluate` (4 calls in `run_duffing.sh`) | `sliced_w2_mean/std`, `q_rel_err`, `q_rel_err_se_paired` |
| Figure: Duffing trajectories from one IC | `duffing.plot_ensemble` | `paper_ensemble_paper_{gt,liftdrift}.pdf` |
| Figure: Duffing phase snapshots | `duffing.plot_snapshots` | `phase_snapshots_paper_step{300,600,900,1200}.pdf` |
| Table 2 (RB) | `rb.evaluate` | `sinkhorn_mean/std`, `q_rel_err`, `q_rel_err_se_paired` |
| Figure: RB marginals | `rb.plot_histograms` | `rb_histograms/rb_hist_C{1,2,4,8,9}_t{0,...,2000}.pdf` |
| Table 3 (Burgers) | `burgers.evaluate` | `{energy,enstrophy}_{mean,std}_relerr` |
| Figure: Burgers snapshots | `burgers.plot_snapshots` | `burgers_snapshots_paper_square_step{100,300,500,700}.pdf` |
| Table 4 (turbulence) | `cfd.evaluate` | `{energy,enstrophy}_{mean,std}_relerr` |
| Figure: turbulence trajectories | `cfd.plot_snapshots` | `cfd_snapshots_ic1.pdf` |
| Figure: turbulence ensemble | `cfd.plot_ensemble --op-rollouts data/cfd/operator_rollouts_ic0.npz` | `cfd_ensemble_snapshots_with_op.pdf` |

## Pretrained Models

`checkpoints/` holds the shipped configs, and `scripts/evaluate_pretrained.sh` recomputes all
tables and figures from these pretrained models.
